> **💡 Nota:**  
> Para instalar los paquetes de Node, usa:
>
> ```sh
> npm install
> ```

> **⚠️ Importante:**  
> Asegúrate de tener las siguientes versiones de Node y npm para evitar problemas:
>
> - **Node:** `23.6.0`
> - **NPM:** `10.9.2`
> - **ANGULAR:** `17`

> **💡 Consejos:**  
> Comandos de ejecución del proyecto:
>
> ```sh
> ng serve -o      # Para ejecutar el proyecto
> ng build --configuration=production --output-hashing=all --no-cache   # Para generar un compilado que sirve para refrescar los cambios de typescript y convertirlos a javascript
> npx firebase deploy # Para hostear el proyecto en firebase hosting
> ```
>
